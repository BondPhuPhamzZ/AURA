# Free hosting decision for AURA — 27 October 2026

## Current constraints

AURA currently targets `net8.0`, uses EF Core's SQL Server provider, stores receipts on a private filesystem path by default, and drains a durable SQL queue with ASP.NET hosted background services. The Drive reader is deliberately restricted to Development plus loopback. The owner's SmartASP screenshot shows MSSQL **1/1**: its only database slot is occupied. The 1.1% shown on the database card is used bytes, whereas 1000/1000 MB is allocated disk quota; freeing disk quota would not create a second database slot. Do not delete or migrate the contest database merely to make room for staging.

## Options checked against the actual application

| Option | Fit for unchanged architecture | Material limit |
| --- | --- | --- |
| Azure App Service Free F1 + Azure SQL Database Free | Best candidate for a new, single-instance **web synthetic demo** with a fresh database. Windows App Service has persistent per-app `%HOME%` storage, but the receipt/allowlist locations and access must be verified on the actual app. | F1 has 60 CPU minutes/day, 1 GB storage and no Always On. The app may unload after idle; SQL queue/Drive/retention background tasks are not continuously available. Azure SQL Free has monthly limits and can pause when they are reached. No production/SLA claim. |
| Existing local Windows host with private remote access | Preserves LocalDB, private receipts and worker while the owner's computer remains on. | This is **not cloud hosting**. A tunnel/public URL requires a separate access-control and threat review; machine power, network and OS maintenance remain the owner's responsibility. |
| Oracle Always Free VM | Potentially useful after architecture changes. | Free AMD micro has 1 GB RAM; SQL Server on Linux requires at least 2 GB and x64. Free ARM has more RAM, but SQL Server on Linux supports x64 only. A database migration or separate SQL service is required. |
| Render/Koyeb free web, Cloud Run request-based | Useful for stateless prototypes. | Free web instances sleep/scale to zero; local files are disposable or cannot have a free persistent volume. Cloud Run request billing does not guarantee continuous worker CPU. They require external SQL Server and object storage or larger code/architecture changes. |

Primary sources: [Azure App Service quotas](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/azure-subscription-service-limits), [Azure App Service idle behavior](https://learn.microsoft.com/en-us/azure/app-service/configure-common), [Windows App Service persistent files](https://learn.microsoft.com/en-us/azure/app-service/operating-system-functionality), [Azure SQL Free limits and restore restriction](https://learn.microsoft.com/en-us/azure/azure-sql/database/free-tier-faq), [Oracle Always Free shapes](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm), [SQL Server Linux requirements](https://learn.microsoft.com/en-us/sql/linux/install-upgrade/setup), [Render Free limits](https://render.com/docs/free), [Koyeb Free limits](https://www.koyeb.com/docs/reference/instances), [Cloud Run billing and background CPU](https://docs.cloud.google.com/run/docs/configuring/billing-settings).

## Recommended order

1. Keep the SmartASP contest database and local synthetic profile unchanged. Back up the existing SmartASP database, website and receipts before the trial ends. No extra SmartASP MSSQL quota purchase is needed just to test the new candidate.
2. If eligible, the owner registers for **Azure for Students** through the [official page](https://azure.microsoft.com/en-us/free/students/), verifies the school email and confirms the subscription is *Azure for Students*, **not Azure for Students Starter**. The former does not require a credit card at signup; SQL Free is currently incompatible with Starter. If ineligible, inspect the standard [Azure Free](https://azure.microsoft.com/en-us/free/) signup and billing terms before proceeding. Never share account credentials or payment details with the project.
3. In the Azure portal, create a **new** SQL Database through [Azure SQL hub](https://learn.microsoft.com/en-us/azure/azure-sql/database/free-tier): choose **Start free**, verify the **Free offer applied** banner and estimated monthly cost zero, choose **Auto-pause until next month when free limits are reached**, and avoid paid add-ons. Free-tier SQL cannot restore the old SmartASP `.bak`; create an empty synthetic database and apply the current migrations instead.
4. Create a **Windows, Code, Free F1** App Service under the same subscription, without optional paid resources. Configure Production, `DriveSandbox__Enabled=false`, `Verify__Enabled=false`, `ApprovedImagesOnly`, ZDR/data-collection routing, one instance/AI permit and a private persistent receipt/allowlist path under the app's actual `%HOME%`. Do not upload real receipts, the Drive JSON key or the local active profile. Restrict access to the demo; AURA tabs are not authentication.
5. Before deploying, verify an Azure-supported runtime. The current project is .NET 8, whose support ends **10 November 2026**. Prepare a separate .NET 10/EF Core 10 compatibility branch, build, full regression, migration-script review and synthetic local smoke, while preserving the contest source/tag. Do not claim long-term security maintenance from .NET 8 after its support date.
6. Deploy only after the account, free-offer and runtime gates are confirmed. Check `/healthz`, one approved and one blocked synthetic upload, SQL/audit/Undo, receipt access after restart, idle/wake behavior and the free-tier usage meters. No 24/7 Drive or retention guarantee on F1. If those checks fail, keep local as the supported demo rather than changing SQL provider or weakening the privacy gate.

The Azure hosting free tiers do **not** cover OpenRouter inference charges. Azure for Students credit is time-limited and exhaustion can disable the subscription; monitor usage and keep an independent backup. [Azure for Students terms](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p), [education FAQ](https://learn.microsoft.com/en-us/azure/education-hub/faq), [.NET support policy](https://dotnet.microsoft.com/en-us/platform/support/policy).
